# Архитектура прототипа

## Цель

Запустить неизменённый Windows-бинарник DataExpress на Android ARM64 без установки Windows и без передачи данных на удалённый сервер.

## Слои

1. **Android launcher** — выбор базы, разрешения, диагностика и запуск.
2. **Runtime manager** — распаковка подписанного runtime-пакета, проверка SHA-256, версии и свободного места.
3. **Display/input** — вывод окон Wine, мышь, сенсор, аппаратная и экранная клавиатуры.
4. **Box86/Box64** — динамическая трансляция Linux x86/x86_64-кода в ARM64.
5. **Wine** — реализация Win32/Win64 API.
6. **DataExpress payload** — собранный в CI Win32-каталог приложения и Firebird embedded.
7. **Database staging** — постоянная учебная база и отдельная рабочая копия каждого внешнего URI.

## Принцип распространения

Preview APK включает Winlator runtime, DataExpress, Firebird и одну официально опубликованную учебную базу. Для каждого компонента фиксируются:

- источник;
- версия и commit/tag;
- лицензия;
- SHA-256;
- список патчей;
- обязательные notices.

## Сценарии запуска

1. Обычный Android `LAUNCHER` intent распаковывает runtime при необходимости и открывает встроенную `DEMO_DB.DXDB`.
2. Android `VIEW` intent для `.DXDB/.FDB` принимает `content://` URI от системного файлового менеджера, в том числе USB-провайдера.
3. Внешняя база копируется в `C:\\DataExpress\\databases\\external\\<uri-hash>`; каталоги разных баз не пересекаются.
4. При штатном завершении DataExpress рабочая копия записывается обратно в исходный URI. При ошибке она остаётся внутри приложения для восстановления.
5. В DataExpress передаётся реальный путь базы первым аргументом командной строки, поэтому используется штатный desktop-код открытия базы и PascalScript.

## Не включено в MVP

- полная эмуляция Windows;
- драйверы Windows;
- гарантированная поддержка Microsoft Office COM;
- гарантии для драйверов ядра, 64-битных DLL и внешних приложений, отсутствующих в Wine;
- публикация в Google Play или AppGallery.
