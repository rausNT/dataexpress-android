# Архитектура прототипа

## Цель

Запустить неизменённый Windows-бинарник DataExpress на Android ARM64 без установки Windows и без передачи данных на удалённый сервер.

## Слои

1. **Android launcher** — выбор базы, разрешения, диагностика и запуск.
2. **Runtime manager** — распаковка подписанного runtime-пакета, проверка SHA-256, версии и свободного места.
3. **Display/input** — вывод окон Wine, мышь, сенсор, аппаратная и экранная клавиатуры.
4. **Box64** — динамическая трансляция Linux x86_64-кода в ARM64.
5. **Wine** — реализация Win32/Win64 API.
6. **DataExpress payload** — сторонний каталог приложения и Firebird-компоненты, добавляемые отдельно.

## Принцип распространения

Базовый APK не должен содержать Wine, Box64, DataExpress или Firebird до завершения лицензионной проверки. Runtime устанавливается отдельным пакетом, в котором у каждого компонента зафиксированы:

- источник;
- версия и commit/tag;
- лицензия;
- SHA-256;
- список патчей;
- обязательные notices.

## Первый технический POC

1. Проверить ABI устройства — только `arm64-v8a`.
2. Подготовить минимальный Wine/Box64 runtime.
3. Запустить `wineboot` и простой Windows x64 executable.
4. Подключить графический backend.
5. Запустить DataExpress без базы.
6. Открыть тестовую `.DXDB`.
7. Проверить Firebird, кириллицу, DPI, клавиатуру и файловые диалоги.
8. Зафиксировать совместимость расширений, DLL, COM/OLE и печати.

## Не включено в MVP

- полная эмуляция Windows;
- драйверы Windows;
- гарантированная поддержка Microsoft Office COM;
- совместимость со всеми расширениями DataExpress;
- публикация в Google Play или AppGallery.
