# Лицензирование и комплект поставки

Этот документ является инженерным чек-листом, а не юридическим заключением.

## Собственный код

До выбора окончательной лицензии собственный код Android-оболочки не следует считать разрешённым для свободного копирования или распространения. Отдельный файл `LICENSE` будет добавлен после решения владельца проекта.

## Сторонние компоненты

Перед включением любого бинарника в APK, runtime-пакет или GitHub Release необходимо зафиксировать:

| Компонент | Что проверить |
|---|---|
| Wine | точная версия, лицензии LGPL, исходники применённых патчей, notices |
| Box64 | точная версия, лицензия, патчи и способ динамического связывания |
| Winlator | используется ли код непосредственно или только архитектурные идеи; лицензии каждого заимствованного файла |
| Firebird | версия клиента/сервера, IPL/IDPL notices и право на распространение выбранных файлов |
| DataExpress | лицензия исходного проекта и право распространять собранный Windows-бинарник, ресурсы и зависимости |
| Шрифты и библиотеки | лицензия каждого включённого файла |

## Предпочтительная модель MVP

1. APK содержит только собственную оболочку.
2. Runtime загружается отдельно из контролируемого источника.
3. Manifest runtime содержит URL, версию, SHA-256 и перечень лицензий.
4. DataExpress payload пользователь добавляет самостоятельно либо получает из официального источника.
5. В интерфейсе доступен экран «Лицензии компонентов».

## Запрещённые упрощения

- нельзя считать весь Winlator единым компонентом с одной лицензией;
- нельзя распространять Wine/Box64 без исходников или предусмотренного лицензией способа их получения;
- нельзя автоматически публиковать `DataExpress.exe`, пока право его распространения не подтверждено;
- нельзя скрывать модификации сторонних компонентов.
