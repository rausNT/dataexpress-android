# Лицензирование и комплект поставки

Этот документ является инженерным чек-листом, а не юридическим заключением.

## DataExpress

Официальный проект `dxbit/dataexpress` опубликован под Apache License 2.0. Лицензия разрешает собирать и распространять DataExpress как в исходной, так и в объектной форме, включая `DataExpress.exe`, при соблюдении условий лицензии.

В каждом runtime-пакете должны присутствовать:

- исходный `LICENSE.txt` из `dxbit/dataexpress`;
- исходный `NOTICE.txt`;
- точный commit SHA исходников;
- перечень наших изменений и способ получить соответствующие исходники;
- SHA-256 собранного бинарника.

DataExpress должен собираться в CI из закреплённого commit SHA. Не следует без проверки копировать готовый каталог старого дистрибутива.

## Исключаемые компоненты

`NOTICE.txt` DataExpress перечисляет сторонние зависимости. Компоненты с отдельной или проприетарной лицензией проверяются отдельно.

На первом этапе запрещено включать в runtime:

- `PadegUC.dll`, поскольку в NOTICE она обозначена как проприетарная;
- DLL и исполняемые файлы неизвестного происхождения;
- файлы, для которых отсутствует лицензия или воспроизводимый источник сборки.

Сборка должна завершаться ошибкой, если в payload обнаружен файл из deny-list.

## Остальные компоненты

| Компонент | Требование |
|---|---|
| Wine | фиксированная версия, LGPL notices, публикация применённых патчей и исходников |
| Box64 | фиксированная версия и commit SHA, лицензия и патчи |
| Firebird | IPL/IDPL notices, только необходимые runtime-файлы |
| Winlator | код копируется только после проверки лицензии конкретного файла; архитектурные идеи можно реализовать независимо |
| Шрифты | лицензия каждого включённого файла |

## Модель поставки

1. Android APK содержит оболочку и runtime installer.
2. Runtime собирается воспроизводимо в CI и публикуется отдельным архивом.
3. Manifest содержит версии, commit SHA, размеры, SHA-256 и ссылки на исходники.
4. В runtime разрешено включать собранный из официальных исходников `DataExpress.exe`.
5. В приложении доступен экран «Лицензии компонентов».

## Автоматические проверки

Перед публикацией runtime CI обязан:

- проверить наличие LICENSE/NOTICE;
- проверить deny-list файлов;
- сформировать SBOM/manifest;
- вычислить SHA-256;
- сохранить журнал сборки и commit SHA всех исходных проектов;
- не публиковать артефакт при неполной лицензионной информации.
