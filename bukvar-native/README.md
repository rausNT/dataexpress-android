# Букварь: нативная Android-версия

Версия 1.0.0-native. Пакет `ru.ratunov.bukvar.nativeapp`, минимум Android 6 / API 23, target API 35.

Все экраны — Android Views, корневая разметка в XML. WebView, HTML, CSS, JavaScript, внешних страниц, рекламы, аналитики и зависимостей Google Play Services нет. Системные шрифты не включаются в дистрибутив.

9 вводных занятий и 54 задания перенесены из предыдущего прототипа. Это не полный перенос букваря 1955 года. Устное выделение звука → буква → соединение звуков → сборка слова → самостоятельное чтение. Авторские подсказки взрослому. Собственная строка, крупный шрифт, ночные цвета, сохранение отметок.

## Голос
Запись себя и образца взрослого — нативный MediaRecorder AAC/M4A; воспроизведение — MediaPlayer. Записи находятся только в cache приложения и удаляются при выходе из задания. При уходе в фон запись останавливается. Автоматическое распознавание — через установленный системный сервис после согласия взрослого; провайдер может обрабатывать голос на сервере. На Huawei сервис может отсутствовать: доступна запись/прослушивание, но не ложная «успешная» проверка. Отдельные звуки автоматически не оцениваются. TTS используется только для целых слов/строк при наличии русского голоса.

## Сборка
JDK 17, Gradle 8.13, Android SDK 35, build-tools 35.0.0.

```
python3 prepare.py
gradle :app:testReleaseUnitTest :app:assembleRelease
```

APK подписан тестовым ключом. Это сборка для прямой установки и испытаний, не релиз в магазине. Новый package id позволяет установить рядом со старым прототипом.

## Проверки
`.github/workflows/bukvar-native.yml` собирает APK единожды, проверяет подпись V1/V2 и архив, запускает unit-тесты, затем устанавливает этот же release APK в два настоящих Android-эмулятора. `tools/smoke.py` выполняет действия через ADB и считывает UIAutomator-дерево; скриншоты снимаются командой screencap. Речь ребёнка не моделируется и не выдается за проверенную. На физическом Huawei тестов нет.
