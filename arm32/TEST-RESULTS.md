# ARM32 Test 1: проверка на Xiaomi Android TV

Итог: **учебная база DataExpress успешно открылась после автоматической подготовки, повторный запуск из кеша прошёл, меню отвечает на указатель.** Это ограниченная проверка одного устройства и встроенной базы.

## Проверенная сборка

- Package: ru.mydataexpress.tv32; Android 8+; armeabi-v7a.
- Version: 0.1-tv-arm32-test.1; debug APK.
- APK: DataExpress-TV-ARM32-0.1-test.1.apk, 151115213 bytes.
- SHA256: `2C1266CB3E546549FA4F236546250434A4EB06588C1AA229DBFA608520537749`.
- Gradle build completed successfully. Final APK custom scan in Microsoft Defender produced no new detections.

## Устройство и результат

Xiaomi MiTV_MSSP0 / amelie, Android 9, ARM32 Cortex-A53, около 929 МБ RAM, GLES2. Проверка выполнена 7 октября 2026 года.

- APK установлен и запущен через Android TV activity. Кнопка подготовки доступна с DPAD_CENTER.
- Последний чистый запуск: подготовка началась в 01:41:20.217, извлечение runtime завершилось в 01:42:19.033 — **58.822 с**. Ранее XZ извлекался за 178.710 с; Zstd в других итерациях — 64.619 и 67.571 с.
- Первичная настройка Wine: 01:42:20.647–01:44:08.406 — **107.759 с**. Она создаёт private prefix, registry и Windows DLL layout. Эти этапы выполняются один раз.
- DataExpress запущен автоматически. Снимки подтвердили заголовок DEMO_DB, записи, поставщика АШАН, позиции Samsung 942DXsw / Майка и сумму 675.00.
- Повторный запуск: `Using cached runtime` в 01:48:40.061, запуск DataExpress в 01:48:41.229. Полностью заполненное окно подтверждено снимком к 01:49:59 — около **80 с верхней границы** от нажатия кнопки. Точный момент появления окна между снимками не измерен; это не точный benchmark запуска.
- Меню «Файл» открывается обычным небольшим окном, реагирует на указатель. Мышь проверялась через ввод Android; запуск с кнопки — через пульт.

## Найденные и устранённые блокеры

GLES3 заменён на GLES2; старый PRoot, вызывавший повреждение стека Box86, заменён современной Termux-версией; ARM loader получил корректную точку входа. Wine server запускается через Box86. GNU strip изменял PE section flags — они восстанавливаются по оригинальным Debian-файлам. Пустая папка prefix больше не создаётся заранее. Отдельная zlib1.dll устанавливается в prefix автоматически. Гостевой сценарий ждёт Wine server, чтобы завершение Explorer не уничтожало запущенный DataExpress. Windows USB/HID drivers отключены в TV-профиле после наблюдения задержек с Wine device/PlugPlay processes.

## Ограничения

Скорость запуска всё ещё требует улучшения. Журнал содержит предупреждения DNS (`res_query` / libresolv), отсутствующего X11 SHAPE extension и SysV preload. Они не помешали проверенному открытию учебной базы, но сетевые подключения и прочие функции не подтверждены. Реальные пользовательские базы, печать, отчёты, обмен данными, длительная работа и другие ARM32-устройства не проверялись. Это техническая экспериментальная ветка с профилем TV, а не универсальный готовый выпуск.

Старый загруженный upstream Winlator_6.1.apk был ранее удалён Defender; он никогда не запускался и не устанавливался. Его бинарный runtime не входит в этот APK. Исключения антивируса не добавлялись.

## Удаление после теста

По просьбе владельца TV тестовый пакет удалён через adb uninstall без сохранения данных. Удалены наш private runtime/Wine prefix, диагностические файлы dataexpress-tv-* из /data/local/tmp и наши screenshot/UI-dump файлы из /sdcard. Проверки подтвердили отсутствие пакета, тестовых процессов и этих временных файлов; run-as сообщает unknown package. ADB-соединение с этим TV отключено. Другие приложения и ранее существовавшие файлы устройства не удалялись.
